## 📓 Основное исследование (Jupyter Notebook)

Весь процесс анализа данных, поиска инсайтов и проверки гипотез оформлен в интерактивном блокноте.

👉 **[Смотреть Jupyter Notebook с анализом](notebooks/01_funnel_and_ab.ipynb)**

**Что внутри ноутбука:**
1. **Построение воронки:** Расчет уникальных пользователей на каждом шаге (от регистрации до покупки подписки) и выявление узких мест с визуализацией.
2. **Поиск Aha-момента (Корреляционный анализ):** Подготовка фичей пользователей и построение модели **Логистической регрессии**, которая доказала, что использование AI-ассистента — главный предиктор конверсии (p-value < 0.05).
3. **Оценка A/B-теста:** Проведение статистического **Z-теста долей** для оценки эффективности нового онбординга (с фокусом на AI). Эффект статистически значим, нулевая гипотеза отвергнута.
